04 · The product

Students write by hand.
Valed tutors on their ink.

Solve in ℝ:  2x² − 5x + 2 = 0
a = 2,  b = −5,  c = 2✓
Δ = 25 − 16 = 9  →  √Δ = 3✓

Valed · Ink Tutor

Check the denominator: the formula divides by 2a, not 2. What is 2a here?

Every mark is drawn on the student's own handwriting — and verified against it.
  • Reads the whole page — equations, tables, sketched graphs — like a human tutor.
  • Finds the first real error — the cause, not the symptom. It re-derives every step before flagging one.
  • Marks the ink — a check, a circle, a highlight — then asks one Socratic question. The final answer never comes.
  • A hard trust boundary. The model proposes; the server verifies against the real ink. Hallucinated feedback is structurally impossible.
Every stroke updates a living map of the student solve by hand → exact error diagnosed → mastery graph updates → projected exam grade moves → next best skill

We have not found anything like this on the market.

05 · Why it's hard to copy

Not a ChatGPT wrapper.
A verified reasoning pipeline.

  1. 1

    Ink capture

    Professional handwriting recognition — every symbol, exactly positioned.

  2. 2

    Board understanding

    Bespoke detectors segment the page — equations, tables, graphs — each recognised in isolation.

  3. 3

    Reasoning

    A frontier vision model re-derives every step before it may judge one.

  4. 4

    Trust boundary

    Every mark is validated against the real ink. What can't be verified is never shown.

  5. 5

    Pedagogy

    Hints paced by attempt: point → method → worked step. Never the answer.

Built like infrastructure — circuit breakers, model tiering, a costed roadmap to cut inference cost 40–60%.
